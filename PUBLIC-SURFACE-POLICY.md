# 公開協調表面規則 / Public Coordination Surface Policy

## 中文／Owner View
XL10 對外只公開 **協調模式與 return discipline**，不公開足以還原內部 Core 的完整 receiver graph、authority routing、private evidence lineage 或 internal machine contract。

中文是 Owner／Human Surface，用來降低理解負擔；是否可公開仍由 Audience／Rights／Sensitivity／Release Gate 決定。

## English／External View
XL10 exposes only **public-safe coordination and return patterns**. It does not disclose complete internal receiver graphs, authority routing, private evidence lineage, or machine contracts that could reconstruct internal architecture.

## Machine／Canonical View
Public machine metadata stays minimal and release-safe.

```yaml
surface: public-coordination
human_language: zh-TW
```

## Fixed separations
- Return ≠ Reconciliation
- Receipt ≠ Authority
- Bilingual ≠ Full Disclosure
- Public-safe ≠ Public-approved
- Machine-readable ≠ Public-readable
